\# CodeAlpha Cyber Security Internship Tasks



This repository contains the projects completed as part of the CodeAlpha Cyber Security Internship.



\## Task 1: Basic Network Sniffer



A Python-based network sniffer that captures and summarizes network packets using Scapy.



\*\*Technologies:\*\* Python, Scapy



\*\*Project folder:\*\* `BasicNetworkSniffer/`



\## Task 3: Secure Coding Review



A Python security review project demonstrating a possible SQL injection vulnerability and its remediation using parameterized SQL queries and secure password handling.



\*\*Technologies:\*\* Python, SQLite, Bandit



\*\*Project folder:\*\* `SecureCodingReview/`



\## Repository Structure



\- `BasicNetworkSniffer/` — Network sniffer source code and screenshot evidence.

\- `SecureCodingReview/` — Vulnerable and secure application code, scan reports, and security review.



\## Disclaimer



These projects are for educational purposes and demonstrate basic cybersecurity concepts.
